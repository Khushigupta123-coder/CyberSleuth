PROJECT DOCUMENTATION

How it works.

A transparent, modular workflow for turning unstructured threat reporting into reviewable candidate intelligence.

EXPLAINABLE PIPELINECyberSleuth · NLP mini project
SYSTEM OVERVIEW

From raw language to structured evidence

CyberSleuth combines text preprocessing, pattern-based entity extraction, and rule-based technique correlation. Each result can be traced back to the original report text.

INPUT→NLP→MAP→REVIEW
01
INGESTION

Report input and normalization

The analyst pastes report text or uploads a TXT, MD, or LOG file. Whitespace is normalized and defanged URL prefixes such as hxxps:// are converted for domain extraction.

PythonFlaskText normalization
02
ENTITY EXTRACTION

Identify indicators and security terms

Regular expressions extract IPv4-shaped values, domains, command-line tools, malware terms, phishing language, and selected credential or persistence indicators. These are transparent baseline rules, not a general-purpose NER model.

RegexPattern matchingEntity deduplication
03
TECHNIQUE CORRELATION

Map phrases to candidate ATT&CK techniques

Configured phrase patterns are matched against the report and associated with selected MITRE ATT&CK technique IDs. Supporting sentences are shown so an analyst can inspect the context.

Rule-based mappingMITRE ATT&CKEvidence snippets
04
REVIEW AND REPORT

Present findings with limitations

The dashboard displays counts, entities, candidate techniques, tactics, and evidence. Analysts must validate each result; the current prototype does not perform live threat-intelligence lookups or prove compromise.

Flask templatesHTML/CSSAnalyst validation
CURRENT SCOPE

What this version does

  • Analyze pasted report text
  • Upload TXT, MD, and LOG files
  • Extract selected entities and indicators
  • Show candidate ATT&CK mappings and evidence
  • Search the configured technique library
FUTURE ENHANCEMENTS

Where to take it next

  • Fine-tune a transformer model on an annotated CTI dataset
  • Evaluate precision, recall, and F1-score
  • Add PDF parsing and IOC enrichment
  • Import more complete ATT&CK technique data
  • Export analyst findings as JSON or CSV
!
Research and safety note

Use public or synthetic reports. IP addresses and domains may be placeholders. This educational prototype does not execute samples, scan targets, or verify live indicators.
